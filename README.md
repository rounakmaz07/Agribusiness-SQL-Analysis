# Agribusiness SQL Analysis – Week 4

## Project Overview
This project focuses on analyzing agribusiness production data using SQL and data visualization techniques.

## Project Files
- `Week4_crops_lookup.csv` – Crop information dataset.
- `Week4_farms_lookup.csv` – Farm information dataset.
- `Week4_production_dataset.csv` – Production dataset.
- Google Colab Notebook – SQL analysis and data visualization.
- Project Report – Business insights and findings.

## Tools Used
- Python
- Google Colab
- SQL
- Pandas
- Matplotlib
- Seaborn

## Objectives
- Analyze agricultural production data.
- Identify crop and farm production trends.
- Generate meaningful business insights.
- Present findings through visualizations.

## Conclusion
This project demonstrates how data analysis and visualization can support better agribusiness decision-making.
